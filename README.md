\## Tentang Situs

Website ini dibuat menggunakan WordPress untuk tugas Literasi Digital.

Topik yang dipilih adalah Jejak Digital.



\## Teknologi

\- WordPress, PHP, Apache (XAMPP)

\- MariaDB (database diekspor di db/database.sql)



\## Cara Menjalankan

1\. Salin folder ini ke C:\\xampp\\htdocs\\literasi

2\. Buat database wp\_literasi lalu impor db/database.sql

3\. Salin wp-config-sample.php menjadi wp-config.php dan isi kredensial database

4\. Buka http://localhost/literasi
